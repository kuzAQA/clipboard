# Общий текст

Три общих текстовых поля для обмена текстом между двумя устройствами без аккаунта.

**Откройте сайт:** [kuzaqa.github.io/clipboard](https://kuzaqa.github.io/clipboard/)

## Как пользоваться

1. На первом устройстве нажмите **Создать пару**.
2. Нажмите **Копировать приглашение** и откройте ссылку на втором устройстве. Можно также скопировать ссылку или токен в поле **Вставить токен** и нажать **Подключиться**.
3. Дождитесь статуса **Два устройства**. Введите или вставьте текст в любое из трёх полей — оно появится в том же поле на втором устройстве.
4. Нажмите **Копировать** у нужного поля, чтобы поместить его текст в системный буфер обмена.

Браузер не может незаметно читать системный буфер обмена. Чтобы передать текст из другого приложения, сначала вставьте его в поле на сайте. Для кнопки копирования браузер может запросить разрешение.

Приглашение содержит секретный токен пары: передавайте ссылку только доверенному человеку и не публикуйте её. Текст шифруется в браузере; релей пересылает зашифрованные данные. Истории и постоянного хранения нет.

Нужны интернет и подключение релея на обоих устройствах. Если устройство временно потеряло связь, сайт попробует подключиться снова. В техническом README описаны устройство релея, развёртывание и проверки: [README-clipboard.md](README-clipboard.md).
