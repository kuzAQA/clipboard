# Общий текст

Три общих текстовых поля для двух браузеров без аккаунтов. Публичная страница: `https://kuzaqa.github.io/clipboard/`. Единственный файл фронтенда — `index.html`; GitHub Pages публикует его из workflow `.github/workflows/pages.yml`. Страница подключается к `wss://dogmeet.ru/clipboard/relay`.

## Архитектура

`relay.mjs` работает в отдельном контейнере `clipboard-relay` на VDS. Контейнер не публикует порт наружу и использует существующую Docker-сеть `dogmeet_default`. Caddy принимает HTTPS/WSS на `dogmeet.ru` и отправляет только `/clipboard/relay` в новый контейнер; все остальные маршруты остаются у dogmeet. `FRONTEND_ORIGIN=https://kuzaqa.github.io` ограничивает браузерные WebSocket-подключения.

Токен пары создаётся браузерным Web Crypto и остаётся в части ссылки после `#`. Релей получает только производный идентификатор комнаты и AES-GCM шифротекст; токен и текст не логируются. Комната хранит текущие три значения в памяти, без истории и базы данных. Неактивная комната удаляется через 30 минут. Лимит — два устройства и 1 МиБ на сообщение. После обрыва место устройства освобождается закрытием сокета или проверкой живости (обычно до 10 секунд), клиент повторяет подключение с интервалом от 0,5 до 8 секунд.

## Развёртывание VDS

Из каталога приложения на VDS запустить `docker compose -f compose.relay.yml up -d --build`. Файлы `Dockerfile`, `compose.relay.yml`, `relay.mjs`, `package.json` и `package-lock.json` нужны для контейнера. Конфигурация Caddy требует отдельного маршрута внутри существующего блока `dogmeet.ru`, перед маршрутом приложения:

```caddy
handle /clipboard/relay {
    uri strip_prefix /clipboard
    reverse_proxy clipboard-relay:18787
}
handle {
    reverse_proxy app:3000
}
```

Перед обновлением Caddyfile сохранить его копию, проверить конфигурацию `caddy validate`, затем выполнить reload и проверить `https://dogmeet.ru/` и WSS-релей. Контейнеры приложения и базы dogmeet не перезапускаются.

## Проверка

`npm ci && npm test` проверяет создание пары, обмен всеми тремя слотами, шифрование, снимок при переподключении, занятую пару, ограничение размера и проверку Origin. В браузере откройте страницу на двух устройствах, создайте пару, откройте приглашение и проверьте копирование каждого поля.
